RED vs BLACK - GitHub Pages deployment

1. Extract this ZIP.
2. Create a GitHub repository.
3. Upload the CONTENTS of this folder (index.html, assets folder, .nojekyll) to the repository root.
4. Commit changes.
5. Repository Settings > Pages > Deploy from a branch > main > /(root) > Save.
6. Wait for GitHub Pages to publish, then open the URL shown in Settings > Pages.

Important: Keep index.html and assets/ at the same root level. Do not upload the ZIP itself, and do not place everything inside an extra folder.

Audio: Includes six original sound effects (card flip, deal, shuffle, countdown tick, Red win, Black win). Background music is disabled and no music file is required. Click/tap once on the page to unlock browser audio.
